# Speak Up

A tiny speaking-practice tool: spin a dial to get a random topic, then talk before the timer runs out.

## Modes
- **Off the Cuff** — light, personal prompts
- **Deep Research** — opinion/analysis prompts that need more thought

## Run it
Just open `index.html` in a browser — no build step, no dependencies.

## Host it free on GitHub Pages
1. Push this repo to GitHub.
2. Go to **Settings → Pages**.
3. Set source to the `main` branch, root folder.
4. GitHub gives you a live URL in a minute or two.

## Files
- `index.html` — markup
- `style.css` — all styling
- `script.js` — topic data, spin logic, timer logic
